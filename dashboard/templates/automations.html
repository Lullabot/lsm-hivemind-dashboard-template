Management Commands

launchd

Check status

launchctl list | grep pmdashboard

Stop a job

launchctl unload ~/Library/LaunchAgents/com.pmdashboard.<name>.plist

Start a job

launchctl load ~/Library/LaunchAgents/com.pmdashboard.<name>.plist

Run morning briefing manually

cd automation && ./scripts/morning-briefing.sh

Run retrospector manually

cd automation && ./scripts/retrospector.sh

Run consolidator manually

cd automation && ./scripts/retrospector.sh --phase consolidate
